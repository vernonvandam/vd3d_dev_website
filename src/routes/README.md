# Routes

TanStack Router uses file-based routing. Each route module in this directory defines a page or layout. `__root.tsx` provides the shared application root and renders nested routes through `<Outlet />`.

## Route files

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `services.$service.tsx` | `/services/:service` |

`routeTree.gen.ts` is generated by the TanStack Router Vite plugin. Do not edit it by hand.
